# 🧰 Caja de Herramientas 3D

Lanzador 3D inteligente con **48 sitios web útiles**, agrupados en 10 categorías y mostrados como una galaxia interactiva (Three.js).

**Abrir:** https://siul667766.github.io/caja-de-herramientas-3d/

- Buscador “¿Qué quieres hacer?” que entiende español e inglés (ej.: *quitar fondo*, *unir pdf*, *correo temporal*, *comprimir video*, *pasar archivos al celular*), tolera errores y acentos.
- Clic/toque en una estrella: la cámara vuela hacia ella y muestra la ficha; segundo toque (o “Abrir sitio”) la abre en una pestaña nueva.
- Favoritos ★ y recientes guardados en el navegador. Atajo `/` para buscar. Filtros por categoría.
- Vista de lista 2D (botón ☰ Lista) y respaldo automático si el equipo no soporta 3D. `?vista=lista` y `?q=texto` en la URL.
- Instalable como app (PWA).

Sitio estático: `index.html`, `app.js`, `search.js`, `tools.js`, `style.css`. Sin backend ni claves.
